🎯 Hangman Game (API Based)

A fun Hangman game built using HTML, CSS, and JavaScript.
The game fetches random words from an API, shows the meaning, allows limited hints, and plays sounds for win/lose/correct/wrong actions.

🚀 Features

🎲 Random word fetched using API

📖 Word meaning always visible

💡 Hint system (reveals letters)

🔊 Sounds for:

Correct letter

Wrong letter

Win

Lose

🎉 Confetti animation when you win

🎮 On-screen keyboard (A-Z)

🔁 New Game button

🛠️ Technologies Used

HTML

CSS

JavaScript

API (Random word + meaning)
